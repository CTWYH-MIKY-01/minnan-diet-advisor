# 健康饮食调理（家庭版）

> 漳州本地化 · 纯前端静态网页 · 数据只存本机
> 养生工具 · 版权：王映华 · 【养生参考，不能替代医嘱】

三页式结构：① 今日养生 ② 周食谱 ③ 家人与食物

---

## 一、三个页面分别做什么

### ① 今日养生（index.html）

- **今日信息卡**：日期、星期、今日节气与下一节气倒计时、居住地实时天气、本节气调理重点
- **节气主卡**：当前节气的饮食、起居、运动建议
- **家人今天要注意什么**
  - 一张「当月重点」卡（本节气全家共性要点）
  - 每位家人一行：名字 + 体质标签 + 当月重点一句话
  - 点「查看详细调理」展开：宜吃 / 少吃 / 通经络 / 其他建议 / 慢病提示
- **十二时辰经络运行**（折叠）：默认只显示当前时辰「此刻当令」，点开可看全部十二时辰
- **五运六气常识**（折叠）：默认只显示当前主气，点开可看其余五气

### ② 周食谱（menu.html）

- **全家版**（推荐）：综合所有家庭成员的体质和慢病配餐
- **单人版**：只针对某一位成员配餐
- 可选居住地区（影响天气与当季食材）、起始日期、用餐人数、口味倾向（清淡 / 少油 / 少盐 / 不吃辣 / 爱吃辣）
- 一周 7 天，每天早 / 午 / 晚配主食、主菜、素菜、汤
- 每道菜含：用料与用量、做法步骤、选菜依据、参考视频链接
- 可多次点「生成 / 换一套」；每道菜单独一个「换」按钮，可单菜替换
- 采购清单：全周食材按分类汇总、按人数换算用量，可导出 Excel 带去超市

### ③ 家人与食物（family.html）

- **家庭成员**：称呼、体质（可多选 9 种）、身高体重（自动算 BMI 并给建议）、体检异常（8 类）、口味与忌口备注；每人独立保存、编辑、删除
- **食物甄选**
  - 食物库：85 条常见食材 / 成品菜 / 饮品 / 零食，每条带图标、性味归经、适宜与不宜体质
  - 我的购物车：把想吃的加进来
  - 甄选分析：一键判断「推荐 / 可吃 / 慎吃 / 不宜」，并说明原因和替代建议

## 二、判定规则

- 家里有人患某慢病、且该食物属该病禁忌 → **直接不建议**
- 命中 2 项及以上体质不宜 → **不建议**
- 命中 1 项体质不宜 → **少量慎吃**
- 只命中适宜体质 → **推荐**
- 其余 → **可吃**

## 三、在线使用

手机浏览器打开（部署后）：

`https://你的用户名.github.io/minnan-diet-advisor/`

## 四、部署步骤（约 3 分钟）

1. GitHub 新建仓库，名称 `minnan-diet-advisor`，勾选 Add a README file
2. 上传本目录这些文件：`index.html`、`menu.html`、`family.html`、`style.css`、`README.md`、`js/` 全部 js 文件
3. 仓库 → Settings → Pages：
   - Source：`Deploy from a branch`
   - Branch：`main` / `(root)` → Save
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/minnan-diet-advisor/`

> 已部署过的，更新时只需上传改动过的文件；若改了 CSS 或 JS，记得把三个 HTML 里的 `?v=` 版本号一起改大（例如 `?v=15` 改成 `?v=16`），否则手机浏览器会用旧缓存。

## 五、维护指南

### 加菜 / 改菜：`js/dishes.js`

每道菜字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一，勿重复 |
| `name` | 菜名 |
| `meal` | breakfast / lunch / dinner |
| `role` | staple 主食 / protein 主菜 / veg 素菜 / soup 汤 |
| `tz` | 适宜体质 |
| `badTz` | 不宜体质 |
| `badDis` | 不宜慢病（取值见 rule.js 的 DISEASE） |
| `season` | 春 / 夏 / 秋 / 冬 / 四季 |
| `ing` | 食材 `[{n:名称, a:用量, u:单位, c:分类}]`，按 3 人份标定 |
| `steps` | 做法步骤 |
| `why` | 选菜依据 |
| `video` | 视频搜索关键词 |
| `servings` | 份量 |
| `time` | 耗时 |

### 其他数据文件

| 文件 | 内容 |
| --- | --- |
| `js/rule.js` | 体质 `TIZHI`（9 种）、慢病 `DISEASE`（8 类）、地区 `REGIONS`、当季食材 |
| `js/tcm.js` | 节气中医知识 `JQ_TCM`、体质调理 `TZ_CARE`、十二时辰 `SHICHEN`、五运六气 `WUYUN` |
| `js/jieqi.js` | 24 节气日期推算、节气调理重点 `tiaoli`、节气要点 `JQ_TIP` |

| `js/engine.js` | 配餐引擎 `buildWeek`、采购汇总、体质与慢病合并、选菜评分 |
| `js/storage.js` | 本机存储读写（成员 / 历史 / 地区 / 购物车 / 口味） |

## 六、注意事项

1. **数据只存本机浏览器**（localStorage），不上传任何服务器，换设备或清缓存后不保留
2. 若部署到 GitHub Pages 属**公开访问**，**不要上传私人信息、真实姓名、真实体检数据**；家人在工具里填的内容只存在自己手机里
3. 页面文案保留【养生参考，不能替代医嘱】，勿删
4. 节气日期用「寿星公式」推算，个别年份可能相差 1 天，属推算值
5. 天气来自 Open-Meteo 免费接口，失败时自动降级为文字提示，不影响页面其他功能
6. 甲状腺结节**无需刻意忌碘**（正常碘盐即可），只是不要大量煲海带紫菜汤；真正需要低碘的是甲亢与碘131治疗者
7. 浏览器有强缓存，改完文件务必同步改大 `?v=` 版本号
